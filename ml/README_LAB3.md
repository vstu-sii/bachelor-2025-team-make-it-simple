# Лабораторная работа 3: Прототипирование MVP AI-тьютора

## Описание
Реализация рабочего прототипа AI-тьютора с:
- Baseline моделью (Mistral API)
- Трассировкой через Langfuse
- Сбором метрик и экспериментов
- Полным циклом генерации учебных материалов

## Структура проекта

### Основные файлы:
- `ai_tutor.py` - основной модуль с функциями AI-тьютора
- `config.py` - конфигурация Mistral и Langfuse
- `prompt_templates.py` - шаблоны промптов для всех задач
- `langfuse_integration.py` - интеграция с Langfuse для трассировки
- `experiments_and_metrics.py` - система экспериментов и метрик
- `main.py` - демонстрационная программа

### Вспомогательные файлы:
- `model_selection.md` - обоснование выбора Mistral
- `lab3_report.md` - полный отчет по лабораторной работе
- `run_all_tests.py` - полное тестирование системы
- `requirements_final.txt` - зависимости
