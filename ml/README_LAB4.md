# Лабораторная работа 4: Production-Ready Infrastructure

## Описание
Реализация production-ready инфраструктуры для AI-тьютора с:
- A/B тестированием промптов
- Оптимизацией использования токенов
- Best practices для промпт-инжиниринга
- Анализом качества и производительности

## Структура проекта

### Новые модули:
- `ab_testing.py` - система A/B тестирования промптов
- `prompt_variants.py` - варианты промптов для тестирования
- `prompt_optimizer.py` - оптимизатор промптов
- `lab4_main.py` - основной скрипт лабораторной работы

### Вспомогательные файлы:
- `lab4_plan.md` - план реализации
- `prompt_best_practices_guide.json` - руководство по best practices
- `optimized_*.txt` - оптимизированные промпты
- `ab_results_*.json` - результаты A/B тестирования
