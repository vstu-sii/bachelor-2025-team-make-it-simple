# Выбор Baseline модели для AI-тьютора

## Требования к модели
1. Поддержка русского и английского языков
2. Понимание образовательного контекста
3. Возможность генерации структурированных данных (JSON)
4. Стабильное API
5. Разумная стоимость
6. Низкая задержка (latency)

## Сравнение доступных вариантов

### 1. Mistral AI API (**ВЫБРАНО**)
**Преимущества:**
- Отличное качество на русском и английском
- Хорошее понимание промптов на русском
- Стабильное и быстрое API
- Разумные цены (дешевле OpenAI)
- Несколько моделей на выбор (small, medium, large)
- Поддержка JSON режима в последних моделях

**Недостатки:**
- Требуется API ключ
- Могут быть ограничения по регионам


### 2. OpenAI GPT-4/GPT-3.5
**Преимущества:**
- Хорошее качество генерации
- Средняя поддержка JSON
- Хорошая документация

**Недостатки:**
- Дороже Mistral
- OpenAI может ограничивать доступ из РФ

### 3. Local модели (Llama, Mistral 7B)
**Преимущества:**
- Полная приватность
- Нет лимитов по запросам
- Нет зависимости от API

**Недостатки:**
- Требуют мощного железа (GPU с 8+ GB RAM)
- Сложность настройки
- Ниже качество чем у API моделей
- Высокие начальные затраты

### 4. Hugging Face Inference API
**Преимущества:**
- Много бесплатных моделей
- Хороший выбор моделей с русской поддержкой

**Недостатки:**
- Нестабильное API
- Ограничения по запросам
- Сложная обработка ошибок
- Медленнее коммерческих API

## Обоснование выбора Mistral Medium

### Почему не другие варианты:

1. **Не OpenAI**: Риск блокировок, выше стоимость
2. **Не Local модели**: Нет гарантии наличия GPU у пользователей, сложность деплоя
3. **Не Hugging Face**: Низкая надежность API для production

### Почему именно Mistral Medium:
1. **Качество**: Лучший баланс цена/качество среди доступных API
2. **Языковая поддержка**: Хорошо работает с русско-английскими промптами
3. **JSON генерация**: Может возвращать структурированные данные
4. **Надежность**: Стабильное API с хорошей uptime
5. **Стоимость**: Приемлемая для MVP 

### Альтернативы внутри Mistral:
- **mistral-small**: Дешевле, но качество ниже
- **mistral-large**: Лучшее качество, но дороже (не требуется для MVP)
- **open-mistral-7b**: Бесплатная, но ограниченная версия
